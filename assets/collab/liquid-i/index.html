Mission

Developing the science of multi-agent systems — hyper-agents.

Hyper-agency — the agency that emerges when agents themselves become the substrate for a higher-order agent — is the natural scientific object of Liquid-I, and it is not yet a science.

Classical cognitive science treats individual agents; ecology treats populations; complex-systems work treats coupling. None of these gives us a unified vocabulary or methodology for the higher-order agency that emerges across all the substrates the project studies: cell collectives, multicellulars, brains, eusocial colonies, markets, LLM soups, hybrid AI–human ecosystems, Gaia.

The Synergy proposal is that three converging angles — Solé's, Levin's, Ruffini's — each insufficient alone, together constitute the missing science.

Ruffini — algorithmic agents Solé — complex systems Levin — basal cognition
